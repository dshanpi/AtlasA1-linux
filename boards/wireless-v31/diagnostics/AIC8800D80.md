# AIC8800D80 external-module build candidate

The fitted AW869C/AIC8800D80 identity was confirmed by the user on 2026-11-20.
This is a compile-only candidate against AtlasA1 Linux 6.18.63 GNOME v45.
The board still returns no SDIO ROM response. Neither module has been loaded,
firmware has not been installed, and WLAN/BT operation is not accepted.

Inputs are Tina `bsp/drivers/net/wireless/aic8800/{aic8800_bsp,aic8800_fdrv}`,
BSP release tag `20250923-003`, and the configured, built v45 kernel tree.
Copy these two module directories to an isolated work directory and apply
`aic8800d80-linux618-candidate.patch` there with `patch -p1`.

The patch replaces the vendor's `>= 6.18.21` callback-signature test with the
explicit `AIC_CFG80211_WDEV_API` feature switch. **Leave it undefined for this
kernel**, whose cfg80211 callbacks take `net_device`. Do not enable it merely
because the kernel version number is newer; check its cfg80211 headers first.
The generic platform path uses SDIO in-band interrupts; GPIO host wake and
suspend/resume are not implemented or validated.

```sh
# ksrc/kout: source and configured output from the actual v45 kernel build.
# work: isolated directory containing aic8800_bsp and aic8800_fdrv.
make -C "$ksrc" O="$kout" ARCH=arm64 CROSS_COMPILE=aarch64-linux-gnu- \
  M="$work/aic8800_bsp" CONFIG_AIC_INTF_SDIO=y CONFIG_PLATFORM_ALLWINNER=n \
  KCFLAGS=-DCONFIG_AIC_INTF_SDIO -j5 modules
make -C "$ksrc" O="$kout" ARCH=arm64 CROSS_COMPILE=aarch64-linux-gnu- \
  M="$work/aic8800_fdrv" CONFIG_AIC_INTF_SDIO=y CONFIG_AIC8800_WLAN_SUPPORT=m \
  CONFIG_PLATFORM_ALLWINNER=n KCFLAGS=-DCONFIG_AIC_INTF_SDIO \
  KBUILD_EXTRA_SYMBOLS="$work/aic8800_bsp/Module.symvers" -j5 modules
```

The explicit C macro is required for this external build. The generic platform
choice also avoids unresolved Sunxi-specific WLAN control symbols. This is
not a complete installation recipe: resolve SDIO identity (`c8a1:0182` expected),
select and verify matching firmware, then test the real driver and interface.
Bluetooth firmware is downloaded by the BSP over SDIO before UART HCI use.
